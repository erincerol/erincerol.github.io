How to install it

  1. Gmail: Settings (gear) → See all settings → General → Signature → Create new → paste.
  2. Apple Mail: Settings → Signatures → + → paste. Untick “Always match my default message font” or the styling is stripped.
  3. Outlook: Settings → Mail → Compose and reply → paste into the signature box.
  4. iOS Mail: copy the mobile version above in Safari, then paste into Settings → Apps → Mail → Signature. The field looks like plain text but does accept a rich paste — links and bold survive, colours and the rule usually do not. Long-press → Paste rather than typing.
  5. Gmail app (iOS and Android): the app keeps a separate signature from Gmail on the web, under Settings → your account → Mobile Signature, and that field is plain text only — no links, no styling. Two options: paste the plain-text block below, or clear the mobile signature entirely, which in current versions makes the app fall back to your web signature. The fallback is worth testing by sending yourself one from the phone, because it has changed between releases.
  6. Outlook mobile: plain text only, no fallback. Use the plain-text block.

Worth knowing: no mobile mail app reliably renders a full HTML signature with images. Rather than fight it, the mobile version above is short by design — on a phone the signature repeats on every reply, and a six-app list plus two badges under each one reads as noise.
